# micro-ROS 学习笔记

记录 micro-ROS 在 STM32 和 FreeRTOS 工程中的配置、消息通信与集成过程。

## 推荐阅读顺序

1. [micro-ROS 简介](micro-ROS简介.md)：了解基本架构、应用场景及 STM32 中的使用方式。
2. [详细配置指南](详细配置指南/详细配置指南.md)：从 STM32CubeMX 配置、WSL 和 Docker 环境开始，完成静态库编译与例程构建。
3. [嵌入战队模板](嵌入战队模板/嵌入战队模板.md)：将 micro-ROS 集成到已有工程模板中。
4. [自定义消息](自定义消息/自定义消息.md)：编译自定义消息包，并在微控制器和电脑端使用。
5. [中间件配置](中间件配置/中间件配置.md)：了解通信资源、实体内存池及运行时配置。
6. [网口传输](网口传输/网口传输.md)：配置以太网通信与代理端，验证网口传输。

## 使用说明

这些笔记记录了具体工程的配置过程。使用时请根据开发板、晶振频率、串口、ROS 2 版本和工程目录调整示例参数。
